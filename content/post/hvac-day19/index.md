━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Day 19 - 냉매 종류와 특성
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

안녕하세요! 오늘은 냉동 사이클의 주인공, 냉매(Refrigerant)에 대해 공부합니다. 최근 환경규제 강화로 냉매 전환이 큰 이슈가 되고 있어서, 기술사 시험에서도 출제 빈도가 높은 주제예요.

━━━ 냉매란? ━━━

냉매는 냉동 사이클에서 열을 운반하는 작동 유체입니다. 증발기에서 열을 흡수하고 응축기에서 열을 방출하면서, 끊임없이 액체와 기체 사이를 오갑니다.

좋은 냉매의 조건:
- 적절한 증발/응축 압력 (너무 높지도 낮지도 않게)
- 큰 잠열 (적은 순환량으로 많은 열 운반)
- 화학적 안정성 (분해되지 않을 것)
- 무독성, 불연성 (안전)
- 윤활유와의 호환성
- 환경 친화적 (ODP=0, 낮은 GWP)

━━━ 냉매 명명법 ━━━

R-숫자로 표기하며, 숫자에 의미가 있습니다.

단일 성분 냉매 (R-XYZ):
- X: (탄소수 - 1) → 0이면 생략
- Y: (수소수 + 1)
- Z: 불소수

예) R-134a: C=1(생략), H=3+1-1=3? 아, 좀 더 정확하게 정리하면
R-134a → 1(C-1=2, C=2), 3(H+1, H=2), 4(F=4) → C2H2F4
접미사 a는 이성질체 구분

자연냉매는 700번대:
- R-717 = 암모니아 (NH3, 분자량 17)
- R-718 = 물 (H2O, 분자량 18)
- R-744 = 이산화탄소 (CO2, 분자량 44)

혼합냉매는 400번대(비공비), 500번대(공비):
- R-407C, R-410A 등

━━━ 주요 냉매 특성 비교 ━━━

(1) R-134a (HFC)
- 용도: 차량 에어컨, 소형 냉장고
- ODP: 0 / GWP: 1430
- 특징: 무독성, 불연성, CFC-12 대체냉매
- 현황: 높은 GWP로 점차 퇴출 중

(2) R-410A (HFC 혼합)
- 용도: 가정용/상업용 에어컨 (현재 가장 많이 사용)
- ODP: 0 / GWP: 2088
- 특징: R-22 대체, 운전압력 높음, 비공비 혼합냉매
- 현황: 높은 GWP로 R-32로 전환 추세

(3) R-32 (HFC)
- 용도: 차세대 에어컨 냉매
- ODP: 0 / GWP: 675
- 특징: R-410A 대비 GWP 1/3, 약간의 가연성(A2L 등급)
- 현황: 일본, 유럽 중심으로 빠르게 확대 중

(4) R-407C (HFC 혼합)
- 용도: 기존 R-22 시스템 레트로핏
- ODP: 0 / GWP: 1774
- 특징: 비공비 혼합냉매, 온도 글라이드 존재
- 현황: 과도기 냉매, 장기적으로 퇴출 예정

(5) R-744 (CO2, 자연냉매)
- 용도: 대형 냉동창고, 슈퍼마켓, 급탕 히트펌프
- ODP: 0 / GWP: 1
- 특징: 초고압 운전(임계점 31도C/7.4MPa), 초임계 사이클
- 현황: 유럽 중심 확대, 높은 외기온에서 효율 저하 과제

(6) R-717 (암모니아, 자연냉매)
- 용도: 대형 산업용 냉동, 제빙, 식품공장
- ODP: 0 / GWP: 0
- 특징: 최고 수준의 열역학적 성능, 강한 독성과 냄새
- 현황: 산업용에서 꾸준히 사용, 간접냉방 시스템으로 안전성 확보

━━━ 환경 지표 정리 ━━━

ODP (Ozone Depletion Potential): 오존층 파괴지수
- CFC(R-12 등): ODP = 1 → 몬트리올 의정서로 전폐
- HCFC(R-22): ODP = 0.055 → 2030년 전폐
- HFC(R-134a, R-410A): ODP = 0 → 하지만 GWP 문제!

GWP (Global Warming Potential): 지구온난화지수
- CO2 기준 = 1
- R-134a = 1430, R-410A = 2088 → 규제 대상
- R-32 = 675 → 과도기 대안
- 자연냉매(CO2, NH3) → GWP 0~1, 궁극적 대안

━━━ 냉매 선정 기준 ━━━

기술사 답안에서 냉매 선정 시 고려사항을 물으면:

1. 환경성: ODP = 0, 낮은 GWP
2. 안전성: 독성(A/B 등급), 가연성(1/2L/2/3 등급)
3. 열역학적 성능: COP, 체적냉동능력
4. 운전조건: 적정 운전압력, 토출온도
5. 경제성: 냉매 가격, 장비 호환성
6. 규제 동향: F-가스 규제, 키갈리 개정안

━━━ 최근 트렌드: 저GWP 전환 ━━━

키갈리 개정안(2016): HFC 냉매의 단계적 감축 합의
- 선진국: 2019년부터 감축 시작, 2036년까지 85% 감축
- 개도국: 2029년부터 시작

EU F-가스 규제: 2025년부터 GWP 750 이상 냉매 사용 제한 강화

전환 방향:
- 소형 에어컨: R-410A → R-32
- 대형 칠러: R-134a → R-1234ze(E), R-513A
- 냉동/냉장: HFC → CO2(R-744), NH3(R-717)
- 궁극적: 자연냉매 또는 HFO 계열로 수렴

이 트렌드는 기술사 시험에서 최근 몇 년간 반복 출제되고 있으니 꼭 정리해두세요!

Quiz (3문제)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1. R-410A에서 R-32로 전환하는 가장 큰 이유와, R-32 적용 시 주의해야 할 안전 사항은?

Q2. R-744(CO2) 냉매가 일반 HFC 냉매와 다른 점 2가지를 열역학적 관점에서 설명하시오.

Q3. 냉매의 ODP와 GWP를 모두 설명하고, 현재 냉매 규제의 흐름을 시대순으로 정리하시오.

━━━ 정답 ━━━

A1. 가장 큰 이유는 GWP 저감입니다. R-410A의 GWP는 2088인 반면 R-32는 675로 약 1/3 수준이며, 키갈리 개정안과 F-가스 규제에 대응할 수 있습니다. 또한 R-32는 단일냉매라 충전/회수가 편리하고 열역학적 성능도 우수합니다. 다만 R-32는 A2L 등급의 미연성(mildly flammable) 냉매이므로, 누설 감지기 설치, 환기 확보, 충전량 제한 등 안전 대책이 필요합니다.

A2. (1) CO2는 임계온도가 31.1도C로 매우 낮아, 외기온이 높은 조건에서는 응축이 불가능하여 초임계 사이클(transcritical cycle)로 운전해야 합니다. 일반 HFC는 아임계(subcritical) 사이클로 운전됩니다. (2) CO2의 운전압력이 매우 높습니다(고압측 약 8~12MPa). R-134a의 응축압력이 약 1MPa인 것과 비교하면 약 10배 높아, 내압 설계가 필요하고 배관/부품 규격이 달라집니다.

A3. ODP(Ozone Depletion Potential)는 오존층 파괴 정도를 나타내는 지수로, CFC-11을 기준(1.0)으로 합니다. GWP(Global Warming Potential)는 지구온난화 기여도를 나타내는 지수로, CO2를 기준(1)으로 100년간의 영향을 비교합니다.

규제 흐름:
1단계) 몬트리올 의정서(1987): CFC 전폐 → ODP 대응
2단계) 코펜하겐 개정(1992): HCFC 단계적 감축 → ODP 대응
3단계) 교토의정서(1997): HFC를 온실가스로 지정 → GWP 인식
4단계) 키갈리 개정안(2016): HFC 단계적 감축 합의 → GWP 대응
5단계) EU F-가스 규제 강화(2024~): 구체적 GWP 상한 적용

요약하면 "ODP 해결 → GWP 대응"으로 규제가 진화해왔습니다.
