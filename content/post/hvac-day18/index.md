━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Day 18 - COP 계산 실습
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

안녕하세요! 오늘은 실제 숫자를 가지고 COP를 계산하는 연습을 합니다. 기술사 시험에서 계산 문제는 배점이 크니까, 공식을 손에 익혀두는 게 정말 중요해요.

━━━ COP 공식 정리 ━━━

냉동 COP = 냉동효과 / 압축일

COP = (h1 - h4) / (h2 - h1)

각 점의 위치 (복습):
- h1: 증발기 출구 = 압축기 입구 엔탈피
- h2: 압축기 출구 = 응축기 입구 엔탈피
- h3: 응축기 출구 = 팽창밸브 입구 엔탈피
- h4: 팽창밸브 출구 = 증발기 입구 엔탈피 (h4 = h3)

분자 (h1-h4): 증발기에서 냉매가 흡수한 열 = 냉동효과
분모 (h2-h1): 압축기가 투입한 일 = 압축일

━━━ P-h 선도에서 엔탈피 읽기 ━━━

P-h 선도에서 각 점의 엔탈피를 읽는 요령:

점1 (압축기 입구): 증발압력과 포화증기선의 교점에서 가로축으로 내려 읽기. 과열도가 있으면 포화증기선 오른쪽으로 이동.

점2 (압축기 출구): 점1에서 등엔트로피선을 따라 응축압력까지 올라간 점.

점3 (응축기 출구): 응축압력과 포화액선의 교점. 과냉도가 있으면 왼쪽으로 이동.

점4 (팽창밸브 출구): 점3에서 수직으로 내려와 증발압력과 만나는 점. h4 = h3!

━━━ R-134a 물성표 활용 예제 ━━━

조건: 증발온도 0도C, 응축온도 40도C, 과열도/과냉도 없음

R-134a 물성값:
- 증발온도 0도C: 포화증기 엔탈피 h1 = 398.6 kJ/kg
- 응축온도 40도C: 포화액 엔탈피 h3 = 256.4 kJ/kg
- 등엔트로피 압축 후: h2 = 428.3 kJ/kg

계산:
h4 = h3 = 256.4 kJ/kg (등엔탈피 팽창)

냉동효과 = h1 - h4 = 398.6 - 256.4 = 142.2 kJ/kg
압축일 = h2 - h1 = 428.3 - 398.6 = 29.7 kJ/kg
COP = 142.2 / 29.7 = 4.79

━━━ 냉동능력 계산 ━━━

냉동능력 Q_e = m x (h1 - h4) [kW]

- m: 냉매 질량유량 [kg/s]
- 1kW = 1kJ/s

단위 변환:
- 1 RT (냉동톤, USRT) = 3.517 kW
- 1 JISRT (일본냉동톤) = 3.861 kW

예: 위 조건에서 냉매유량 0.1 kg/s일 때
Q_e = 0.1 x 142.2 = 14.22 kW = 14.22/3.517 = 4.04 RT

━━━ 압축기 동력 계산 ━━━

이론 압축동력: W_th = m x (h2 - h1)
실제 압축동력: W_act = W_th / η_c

η_c: 압축기 효율 (단열효율, 보통 0.65~0.85)

예: m = 0.1 kg/s, 압축기 효율 0.75
W_th = 0.1 x 29.7 = 2.97 kW
W_act = 2.97 / 0.75 = 3.96 kW

실제 COP = Q_e / W_act = 14.22 / 3.96 = 3.59

━━━ 성적계수와 효율의 관계 ━━━

COP는 "1"을 넘을 수 있습니다! (효율과 다른 개념)

- COP는 효율(η)이 아니라 성적계수입니다
- 효율은 항상 1 이하지만, COP는 보통 2~6 정도
- COP가 높을수록 같은 전력으로 더 많이 냉방 가능

COP에 영향을 주는 요소들:
- 증발온도 높을수록 → COP 증가
- 응축온도 낮을수록 → COP 증가
- 과냉도 클수록 → COP 약간 증가
- 압축기 효율 높을수록 → 실제 COP 증가

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
실전 계산 문제 (3문제)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[문제 1]
R-134a 냉동기, 증발온도 -10도C, 응축온도 45도C
물성값: h1 = 392.3, h2 = 438.5, h3 = 264.1 (단위: kJ/kg)
냉매유량 0.08 kg/s일 때:
(a) 냉동능력 [kW]와 [RT]
(b) 이론 COP
(c) 압축기 효율 0.72일 때 실제 소비전력

[문제 2]
냉동능력 100RT가 필요한 냉동 시스템에서:
h1 = 405, h2 = 440, h3 = h4 = 250 (kJ/kg)
(a) 필요한 냉매 순환량 [kg/s]
(b) 이론 압축동력 [kW]
(c) COP

[문제 3]
동일 냉동기에서 응축온도를 35도C로 낮추면(원래 45도C):
h1 = 392.3, h2_new = 425.0, h3_new = 249.5 (kJ/kg)
COP가 얼마나 개선되는지 문제1과 비교하시오.

━━━ 풀이 ━━━

[풀이 1]
h4 = h3 = 264.1 kJ/kg

(a) Q_e = 0.08 x (392.3 - 264.1) = 0.08 x 128.2 = 10.26 kW
    = 10.26 / 3.517 = 2.92 RT

(b) COP = (h1-h4)/(h2-h1) = 128.2 / (438.5-392.3) = 128.2 / 46.2 = 2.77

(c) W_th = 0.08 x 46.2 = 3.70 kW
    W_act = 3.70 / 0.72 = 5.14 kW

[풀이 2]
(a) 100 RT = 100 x 3.517 = 351.7 kW
    냉동효과 = h1 - h4 = 405 - 250 = 155 kJ/kg
    m = Q_e / (h1-h4) = 351.7 / 155 = 2.27 kg/s

(b) W_th = m x (h2-h1) = 2.27 x (440-405) = 2.27 x 35 = 79.45 kW

(c) COP = 155 / 35 = 4.43

[풀이 3]
h4_new = h3_new = 249.5 kJ/kg
냉동효과_new = 392.3 - 249.5 = 142.8 kJ/kg
압축일_new = 425.0 - 392.3 = 32.7 kJ/kg
COP_new = 142.8 / 32.7 = 4.37

문제1의 COP = 2.77 → 문제3의 COP = 4.37
개선율 = (4.37 - 2.77) / 2.77 x 100 = 57.8% 개선!

응축온도 10도C 낮추는 것만으로 COP가 58%나 향상됩니다. 실무에서 쿨링타워 관리, 응축기 청소가 왜 중요한지 체감되시죠?
