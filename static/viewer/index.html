3D 모델 (NWD 변환)

NWD는 브라우저에서 직접 열 수 없습니다. Navisworks에서 FBX로 내보내거나(파일 → 내보내기 → FBX), Revit에서 IFC로 내보내면 객체 속성까지 함께 불러옵니다. 객체를 클릭하면 속성이 표시됩니다.
